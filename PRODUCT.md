# Quill product context

Confirmed: Otterview Labs project, named Quill, combining JetLinks knowledge capabilities and DocuGen document generation into a new local repository under open-source/quill.

The first delivery is a functional integration for a single shared workspace. Users import and organize source files, inspect extracted content, retrieve facts, fill Word templates and generate documents with source records. Following the initial integration, the user requested a richer knowledge workflow and a full visual upgrade. The knowledge surface and shared shell now use a reading workbench direction; inherited template and writing workflows remain functional within that shell.

Assumptions for this first iteration: Chinese interface, local/self-hosted use, manual confirmation of generated documents, no independent user accounts. No claim of production hardening or public licensing readiness is implied.
