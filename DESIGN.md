# Inherited workbench interface

This functional integration inherits DocuGen's Vue forms, template list, upload and variable-editing layouts. It is not a new visual identity exercise. The shared header is adapted to the light content panels already used by the inherited pages.

Tokens: page `#f8fafc`, content white, foreground `#142536`, secondary `#475569`, action `#245d75`, borders `#dce3e8`. Use existing system text styling; no new remote assets are required. Keep labels visible, controls usable from a keyboard, long generated content wrapped, and layouts responsive. New knowledge and writing screens use the same form spacing and controls as the imported workbench.

Future visual design work should replace inherited emoji and decorative template-list treatments as a coherent pass after the functional workflow has been validated.
